# MRGM（Mouse Reference Gut Microbiome）

**类型：** 小鼠肠道微生物基因组参考目录　**目录层级：** Extended　**状态：** `active_verified`（核查：2026-11-10）

## 它是什么

MRGM 是针对小鼠肠道微生物的非冗余基因组 catalog，并提供分类和功能参考。官网报告 42,245 个非冗余基因组，覆盖 1,524 个原核生物物种；同时提供 Kraken2 和 MetaPhlAn 分类数据库。

## 何时使用

当研究对象是小鼠肠道 shotgun reads、需要小鼠专用分类参考或分析小鼠肠道微生物的分类/功能时，可从 MRGM 下载目录或分类库。

## 与样本 metadata 的边界

MRGM 是微生物基因组与分类功能参考，不是小鼠实验队列的样本信息目录。它不能直接补出某个 BioSample 的年龄、性别、饮食、健康状态、饲养条件或 Run 映射；这些信息仍须回到原始项目记录和论文补充材料。
