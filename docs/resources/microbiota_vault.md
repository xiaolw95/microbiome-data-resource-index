# Microbiota Vault

**类型：** 全球微生物样本保存倡议、collection catalogue 与部分测序数据索引；**目录层级：** Extended；**状态：** active_verified（collection 浏览入口已核实；单样本访问受 depositor 条件限制）；**核查：** 2026-11-11

官网列出 9 个本地 collection、1,400+ 份样本、depositors、样本类型、部分 ENA project/BioSample links，并提供人类和食品的 minimal metadata templates、sample tracking sheet 与采样/保存 SOP。2026 年 launch-phase publication 介绍了标准化的 767 份人类粪便和 157 份发酵食品 16S 数据。此状态表示公开 collection 目录和字段/流程资源可用，不代表所有单样本序列均可公开下载。

**适用：** 从地区/collection 出发查找人类肠道与传统发酵食品的样本、BioSample/ENA accession 和数据提供方；也可复用其最小 metadata 字段与 SOP。

**限制：** Vault 代表本地 collection 保存样本，depositor 保留控制权；实体样本通常需联系本地 collection，序列只有在 depositor 明确请求后才公开。因此 collection 页面可见不表示每个样本的序列和完整 metadata 都可下载。
