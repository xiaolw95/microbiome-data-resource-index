# VIRE（Viral Integrated Resource across Ecosystems）

**类型：** 全球 metagenome-derived virome 资源　**目录层级：** Extended　**状态：** `active_verified`（核查：2026-11-10）

## 它是什么

VIRE 从公共 metagenomes 构建全球病毒基因组目录，并关联样本、研究、生态环境和微生物基因组上下文。2026 年论文报告从超过 100,000 个公开 metagenomic datasets 中识别出 1.7 百万个中/高质量 viral genomes，并预测 89 百万个基因。

## 可提供什么

- 浏览和下载 viral genome 序列、质量指标、预测基因和功能注释；
- 查病毒的 host prediction、分类簇以及对应 metagenome/study metadata；
- 按 host-associated、aquatic、terrestrial、engineered 或 human gut 等环境类别筛选，并链接 SPIRE 和 MetaLog 的相关信息。

数据源来自 ENA/SRA 的公开 metagenomes；论文说明其对纳入集合做了筛选，排除若干人工实验体系、amplicon 和 isolate 数据。资源采用 CC BY-SA 4.0。

## 与宿主 metadata 的边界

VIRE 能把病毒/微生物基因组重新连接到原 metagenome 的生态环境或部分临床上下文，适合 virome 与环境/宿主关联发现；它不是临床问卷或通用人群 metadata 数据库。临床或个体属性的精确样本对应仍需从原始项目、MetaLog、论文和补充表核验。
