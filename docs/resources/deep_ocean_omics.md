# Deep Ocean Omics (DOO)

**资源类型：** microbiome platform / multi-omics atlas　**优先级：** extended　**相关性：** supporting　**状态：** `active_verified`　**核查：** 2026-11-10

## 能提供什么

DOO 将深海生物及其共生微生物的多组学记录集中到同一门户。论文和当前站点报告的数据覆盖 68 个物种、7 个门，包括 72 个基因组、1,112 个 metagenomes、950 个 bulk transcriptomes、15 个 single-cell transcriptomes，以及基因功能、系统发育、共生微生物和化石记录。门户提供不同模块浏览和序列/注释下载。

## 适合什么任务

- 从深海物种或海洋生态系统问题出发寻找 genome、metagenome 和 transcriptome 线索。
- 联合查看宿主物种、共生微生物、基因注释和系统发育上下文。
- 发现海洋/极端环境微生物资源及其相关发表研究。

## 边界与注意事项

- DOO 的许多记录组织在物种、基因组或 omics dataset 层级，不能等同于对每个测序 BioSample 提供完整采样 metadata。
- 它聚焦深海生物与环境，不提供人体参与者年龄、饮食或临床变量。
- 对被链接的原始研究数据，应回到来源库核实 accession、样本数量和使用许可。
