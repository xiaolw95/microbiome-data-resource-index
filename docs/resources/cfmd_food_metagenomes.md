# curatedFoodMetagenomicData (cFMD)

**类型：** 食品 shotgun metagenome 整理资源；**目录层级：** Extended；**状态：** active_verified（2026-11-10）

## 能提供什么
DOMINO 列出的 v1.3.2（2026-06）包含 4,125 个食品 metagenomes、109 个数据集、54 个国家和 18,180 个 MAG；提供食品样本整理 metadata、taxonomy/functional profiles 和重建基因组。GitHub 为主要数据与代码入口，仓库标示 CC BY 4.0。

## 适用范围与限制
适合从食品类型、发酵场景、国家和 metagenome 研究发现数据；不是人体宿主表型数据库，不应期待年龄、性别、疾病或生活方式变量。
