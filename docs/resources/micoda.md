# MiCoDa

**类型：** 全球环境 16S curated/reprocessed dataset　**目录层级：** Extended　**已核查：** 2026-11-11

## 它是什么

MiCoDa v2 是可搜索和下载的 Microbial Community Database，提供不同生态系统中的 curated/reprocessed 16S V4 amplicon 数据（区域约为 515–806）。样本和研究与论文/项目相连，额外技术 metadata（如 sequencer、DNA extraction kit）可从文献补充，原始 reads 位于 INSDC 并带 accession。官方页面也展示不同 collection 和更新后的样本数量；引用时应记录使用的版本/子集，避免混用不同页面口径。

## 可提供什么

- 标准化处理的 16S 数据及样本技术/环境 metadata；
- 数据集、论文和项目链接；
- INSDC accession，帮助回到原始 reads。
- 按用户选择的 sample metadata 筛选，并导出 CSV 格式处理结果。

## 何时使用

用户从环境/采样场景出发寻找可复用的 16S 研究时可用；对母婴或 CRC 问题只能在其收录研究确实符合人群/疾病/部位条件时使用。

## 限制

方法和区域范围固定为 16S V4，适合重处理和跨研究比较，不代表通用 shotgun 或所有菌群数据。环境类型和技术 metadata 的覆盖不等于人体受试者临床/饮食 metadata。官网显示 Creative Commons 4.0 International；重分发前须确认该子集的精确许可版本。
