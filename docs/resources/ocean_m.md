# Ocean-M

**类型：** 海洋微生物多组学平台　**目录层级：** Extended　**状态：** `active_verified`（核查：2026-11-10）

## 它是什么

Ocean-M 汇集全球海洋微生物多组学数据，包含 metagenome、metatranscriptome、metaproteome、meta-metabolome、eDNA、MAG、功能基因和生态互作模块。官网提供 Sample Search、Genome、Interactome 等入口。

## 可提供什么

- 海洋样本/数据集的地理、深度和环境上下文；
- MAG 的组装质量、分类、功能注释和全球分布；
- 多组学数据、微生物群落网络及 marine host–microbe/ecosystem interaction 线索。

2025 年论文报告 54,083 个高质量海洋 MAG 和约 57,288 个多组学数据集；官网当前展示相同规模级别的目录计数。数值会随版本更新，使用时应记录查询日期和实际下载版本。

## 何时使用与限制

适合海洋样本、海洋生态梯度、多组学或海洋微生物基因组发现。此处的 host context 指海洋宿主和生态互作，不是人体疾病或临床人口学信息。当前核对了官网模块和论文，未实测 Sample Search 的 accession 接受范围、下载字段或 API。
