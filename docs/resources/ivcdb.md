# Iridovirus Comprehensive Database (IVCDB)

**资源类型：** microbial knowledgebase　**优先级：** extended　**相关性：** indirect　**状态：** `active_verified`　**核查：** 2026-11-10

## 能提供什么

IVCDB 整理 Iridoviridae 的病毒分离株、基因组及进化/流行病学背景。官网当前显示 310 个 isolate、346 条 genomic sequences、310 个地理记录，包含非冗余蛋白、core genes、基因组共线性、宿主范围、疫苗和可视化检测方法。

## 适合什么任务

- 从水产养殖、鱼类、两栖动物、爬行动物或无脊椎宿主相关的 iridovirus 研究问题发现参考数据。
- 比较病毒分离株地理分布、分类、核心基因和宿主范围。
- 查找疫苗和现场快速检测的文献及知识库入口。

## 边界与注意事项

- 这是单一病毒科的病原知识库，不是一般 virome 或全微生物组 archive。
- Host range 代表病毒分类层面或 isolate-level 的宿主信息，不会提供宿主个体的人口学或临床采样表。
- 下游研究应回查数据库引用的 isolate/source accession 与原始记录。
