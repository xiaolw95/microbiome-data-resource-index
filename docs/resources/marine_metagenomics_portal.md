# Marine Metagenomics Portal (MMP)

**类型：** 海洋微生物基因组/序列参考目录；**目录层级：** Extended；**状态：** active_verified

MMP 聚合 MarRef、MarDB、MarFun、SalDB 等 genome/context 数据库。官网报告 MarRef 有 970 个完整参考基因组、MarDB 有 13,237 个非完整基因组；每条 contextual record 可含约 120 个字段，覆盖采样环境或宿主、taxonomy、phenotype、pathogenicity、assembly 和 annotation。

**适用：** 查海洋微生物 reference genomes、环境/宿主来源、taxonomy 和功能注释；下载 marine reference sets。

**限制：** 主要对象是基因组和序列记录，不是通用 sample/run accession resolver。海洋 host/environment context 不等于人类受试者临床 metadata。

**来源：** [MMP 官网](https://sfb.mmp2.sigma2.no/) · [官方数据库说明](https://sfb.mmp2.sigma2.no/databases/) · [NAR 论文](https://doi.org/10.1093/nar/gkx1036)
