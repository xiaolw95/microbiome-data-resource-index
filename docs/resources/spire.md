# SPIRE

**类型：** 全球 shotgun metagenome 整理资源　**目录层级：** Extended　**状态：** `active_verified`（核查：2026-11-10）

## 它是什么

SPIRE 将公开 shotgun metagenome 样本、研究、基因和 MAG 目录整合到可浏览的环境微生物组资源中。论文首版报告 99,146 个样本、739 项研究，并为样本添加人工整理的 habitat/lifestyle contextual tags。

## 可提供什么

- 按样本、研究、habitat 和 taxonomy 浏览；查询样本关联的环境上下文；
- 统一处理的组装、基因、功能注释、MAG/species clusters 和 mOTU profiling 资源；
- 批量下载 MAG、species cluster、基因调用和 profiling 数据。

样本上下文来自 ENA 字段、适用时的 IMG/M metadata，以及与样本匹配的论文；SPIRE 再用 92 项轻量 microntology 人工标注 habitat/lifestyle。这条证据链对环境和生活方式标签尤其有参考价值，但并非每个样本都有宿主临床或人口学信息。

## 何时使用与限制

适合做全球环境和宿主相关 shotgun metagenome 的二级发现、生态标签浏览，或为基因组/分类研究寻找样本来源线索。它不是测序归档的完整镜像；纳入样本经过质量、冗余和研究筛选，单个 accession 的当前搜索/互链需在使用时复核。当前目录核对了官网 FAQ、下载页和论文，尚未逐项测试 accession 查询。
