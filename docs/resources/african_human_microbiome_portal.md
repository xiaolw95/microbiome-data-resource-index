# African Human Microbiome Portal (AHMP)

**类型：** 区域性人体微生物组整理目录　**优先级：** Extended　**状态：** `active_verified`（官方门户、帮助页和论文确认检索/浏览/下载入口；核查日期：2026-11-10）

## 用途

AHMP 由 H3ABioNet 提供，帮助发现非洲人群相关的公开人体微生物组研究。它适合作为按人群/地理区域寻找数据集的入口，尤其能补充通用测序归档不易直接筛选的研究背景。

## 可提供的信息

- 官方门户提供 metadata 搜索、数据概览、地图和下载入口。
- 门户在本轮核查时报告索引 70 个 BioProjects、14,889 个 BioSamples；这些是门户当前显示的归档记录数，不等同于参与者人数或已纳入分析的样本数。
- 可沿记录检索研究、样本及其外部数据库 accession，并回到原始归档和论文追踪更细的研究信息。
- 具体字段以下载文件和各 BioSample/论文为准。年龄、性别、疾病、身体位点、生活方式或饮食等字段是否存在、粒度如何，需要逐项目核实。

## 使用建议

1. 先在 [AHMP 门户](https://microbiome.h3abionet.org/microbiome/) 按研究条件浏览或搜索，并使用地图/概览判断覆盖范围。
2. 从门户下载候选清单；保留门户的原始 ID 与字段值，不要先将其合并到自定义参与者 ID。
3. 对候选 BioProject/BioSample 回到 NCBI、ENA 或 DDBJ 核实 accession 关系、assay 和 reads availability。
4. 沿论文及 [AHMP 帮助页](https://microbiome.h3abionet.org/microbiome/help/)检查样本采集、宿主表型、队列和补充表。只有存在明确 sample/subject crosswalk 时，才将队列描述映射到具体样本。

## 适用范围与限制

- **优势：** 区域性人体微生物组发现入口；页面把 BioProject/BioSample 记录、空间概览和下载结合起来。
- **边界：** 它是专题整理门户，不保证覆盖所有非洲研究，也不代替 INSDC 原始记录、全文和补充材料。
- **样本映射：** 门户报告 BioSample 数量不代表每条记录都有参与者、采样时间点或精确临床表型的映射。
- **字段/版本：** 当前显示计数会变化；本目录记录的是核查日快照。下载文件字段、ID crosswalk 和每个研究的许可应逐项确认。
