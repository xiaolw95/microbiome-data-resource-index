# Genome Sequence Archive for Human (GSA-Human)

**类型：** 人类组学数据归档　**目录层级：** Extended　**状态：** active_verified

## 它是什么

GSA-Human 是 CNCB-NGDC GSA 家族中管理人类遗传/组学测序数据的归档。其数据模型将 Study、Individual、Sample、Experiment 和 Run 分开，并可记录数据访问委员会（DAC）与访问条件。官方资料也列出 human-associated metagenome 研究模板。

## 可提供什么

- Study、Individual、Sample、Experiment、Run 等人类组学记录及其可见的关联；
- 研究类型、疾病、项目、个体/样本/实验数量及公开或受控访问状态；
- 对获准数据，相关 metadata 表和测序文件的下载入口。

## 何时使用

当研究数据沉积于 GSA-Human，或公开归档不足以解释人群/个体层级关系时，可先检查公开研究记录，再按其 DAC 申请流程获取授权信息。若目标是把某篇论文中的 participant 字段连到 NCBI BioSample，仍必须找到明确的 project/sample crosswalk。

## 限制

- 元数据可见度和序列下载权限依数据集、开放共享状态、授权申请和适用政策而异；
- Study/Individual/Sample/Run 层级不能互相替代；
- GSA-Human 不是对任意公共 microbiome accession 自动补充临床信息的服务；不能绕过 DAC 或数据使用协议。
