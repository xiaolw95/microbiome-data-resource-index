# Metalog

**类型：** 全球 metagenomics contextual data curated resource　**目录层级：** Core　**状态：** active_verified（核心检索/下载能力由 2026 NAR 论文确认；本轮网页访问受限）

## 它是什么

Metalog 是 NAR Database Issue 描述的跨样本类别 contextual metadata 整理资源。论文将它与多个已发表 metadata 数据库进行非穷尽比较，并说明可按多项 metadata 条件组合查询；更复杂的筛选可下载 metadata 后分析。

## 可提供什么

- 多类样本的上下文 metadata 和地理/生态信息；
- 研究、样本与原始论文/序列数据库的链接；
- 可组合检索的 metadata 字段，供筛选特定生态/宿主/疾病条件的数据。
- 论文说明可下载完整数据库或单个研究的数据，且记录含原始 publication/sequence 数据库链接。

## 何时使用

适合在全生态或跨宿主数据集发现中作为补充入口，并用于找到链接的论文和序列记录。对于疾病/人群筛选，应核实 metadata 的 scope 是个体样本、群组还是研究级。

## 限制

论文中的可查询描述不等于每条字段都有 sample-level evidence；必须查看原始记录和数据字典。当前网页在本轮触发 anti-bot 阻断，未直接检查 UI、下载文件或 API；使用时需确认最新 release 和具体 ID crosswalk。论文说明其以 shotgun metagenome 为主，不覆盖 amplicon 和 metatranscriptome。
