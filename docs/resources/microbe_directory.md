# The Microbe Directory

**类型：** 跨微生物类群的人工整理性状/生态知识库；**目录层级：** Extended；**状态：** active_partial；**核查：** 2026-11-11

2025 年论文介绍了接近 18,000 个细菌、古菌、藻类、真菌和病毒物种的人工整理记录，包含约 42 类 phenotypic/ecological traits，例如 Gram stain、病毒 genome type、microbiome source、host 和 extremophile traits。论文提供交互浏览器、GitHub 数据与创建图表的代码入口。

**适用：** 对 sample profiling 得到的 taxa 补充微生物性状、生态来源和宿主相关的物种层背景，辅助对宏基因组结果作生物学解释。

**限制：** 对象是 taxon/species trait，而不是研究、BioSample 或 participant；不能提供某个测序样本的年龄、疾病、饮食或采样 crosswalk。2026-11-11 本轮官网无法打开，具体查询界面、API 和数据包 release 需要复核。
