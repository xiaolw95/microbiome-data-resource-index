# AnimalMetaOmics

**类型：** 非人动物微生物组多组学资源；**目录层级：** Extended；**状态：** active_partial（论文能力已确认，当前门户交互未确认）

2024 NAR 论文描述 metagenome、metatranscriptome、metaproteome 和 pangenome 模块；报告 55,898 个微生物基因组、581 个动物物种、321 个转录组数据集及 326 个蛋白组数据集，并提供分类、功能、表达和蛋白信息。

**适用：** 查找动物宿主相关微生物多组学和功能背景。

**限制：** 论文所列在线门户本轮未能打开；当前检索、下载状态尚未确认。它与 AnimalMetagenome DB 不同：前者偏跨宿主多组学/功能，后者偏动物样本与项目记录。

**来源：** [官方门户](https://yanglab.hzau.edu.cn/animalmetaomics#/) · [NAR 2024](https://doi.org/10.1093/nar/gkad931) · [Figshare 代码/数据记录](https://doi.org/10.6084/m9.figshare.24271138)
