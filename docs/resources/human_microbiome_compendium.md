# Human Microbiome Compendium

**类型：** 人体肠道 16S 统一处理数据集；**目录层级：** Core；**状态：** active_verified（固定版数据包可下载）

Zenodo 当前记录为 v1.1.2（2026-08-20），约 775 MB，含 sample_metadata.tsv、projects.csv、分类表、feature tables 等，许可为 CC BY 4.0。项目持续收集并统一处理来自 SRA 的人体肠道 16S 数据。

**适用：** 复用 gut 16S 丰度/分类结果和样本 metadata；检查目标 project/sample 是否已进入 compendium，并用原始 accession 回查 NCBI/论文。

**限制：** 这是限定人体肠道 16S 的固定 release，不是实时 accession resolver。分类结果可能因 release 而异；字段范围以具体版本文件为准，不能预期自动补齐饮食、生活方式或个体临床 crosswalk。

**来源：** [项目主页](https://microbiomap.org/) · [Zenodo 最新版 v1.1.2](https://zenodo.org/records/22035984) · [论文](https://doi.org/10.1016/j.cell.2024.12.017)
