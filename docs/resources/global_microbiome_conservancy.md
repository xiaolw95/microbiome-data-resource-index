# Global Microbiome Conservancy (GMC)

**类型：** 人体微生物组 biobank、菌株 collection 与受控测序数据入口；**目录层级：** Extended；**状态：** active_verified

GMC 收集来自多个国家与代表性不足人群的微生物组样本，并保存培养分离的菌株及其基因组信息。项目页说明，关联 metadata 需向 GMC 申请或联系；测序数据通过 dbGaP 提供，并需按 participant consent 和 dbGaP 规则正式申请。可从 dbGaP study accession phs002235.v1.p1 进入其测序研究记录。

**适用：** 查找多地区人类肠道菌群和分离株资源，确认研究/受控数据入口及 metadata 联系路径。

**限制：** 不是开放的样本 metadata 搜索或下载 API。临床/人口学字段和 reads 可能受控；必须按同意书、dbGaP 数据使用认证和项目方规则申请。项目首页与 biobank 子页报告的 collection counts 不一致且口径/更新时间未说明，因此本卡不把任一数字作为唯一当前总数。
