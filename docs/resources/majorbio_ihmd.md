# Integrated Human Microbiome Database and Analysis System (Majorbio HMD)

**类型：** 人体多身体位点微生物组浏览平台；**目录层级：** Core；**状态：** active_verified（本轮可读取官方研究/样本页）

官方页面列出 739 个 amplicon studies、228 个 shotgun studies 和 143,314 个 samples。样本页可按身体位点、国家、年龄分布、gender、health condition、测序技术和平台筛选。

**适用：** 从疾病、人群和身体位点出发发现已整理人体微生物组项目与样本候选，再用项目 accession 回原始 archive 和论文核验。

**限制：** 版权页标注 2017–2020；本轮未找到独立论文、固定 release、公开 API 或明确数据许可。age/health filters 不代表 diet/lifestyle 已有或可以样本级映射。

**来源：** [HMD 首页](https://microbiome.majorbio.com/hmd) · [研究浏览](https://microbiome.majorbio.com/hmd/study) · [样本浏览](https://microbiome.majorbio.com/hmd/sample)
