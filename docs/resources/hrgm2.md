# HRGM2（Human Reference Gut Microbiome v2）

**类型：** 人类肠道微生物参考基因组目录　**目录层级：** Extended　**状态：** `active_verified`（核查：2026-11-10）

## 它是什么

HRGM2 是基于人类肠道 shotgun metagenome 构建的近完整微生物基因组目录。官网报告从 41 个国家的 18,111 个 WMS 样本组装出 155,211 个非冗余近完整基因组，覆盖 4,824 个原核生物物种，并提供浏览和 Zenodo 下载入口。

## 何时使用

适合人类肠道微生物分类、参考基因组覆盖、跨地理区域的基因组/功能比较，以及下载近完整 MAG 参考目录。官网注明 CC BY 4.0，引用时仍应遵循数据包中的具体说明。

## 与样本 metadata 的边界

“41 个国家”描述参考目录的采样来源范围，不等于 HRGM2 为每个贡献样本提供年龄、性别、饮食、健康状况或 BioSample crosswalk。若要复用人群特征，应沿具体输入研究的 accession 和原文/补充表回溯。
