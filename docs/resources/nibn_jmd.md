# NIBN JMD (Japan Microbiome Database)

**类型：** 人群队列微生物组数据库与分析平台　**优先级：** Core　**状态：** `active_verified`（官方公开版入口已核；全量浏览需注册，核对：2026-11-10）

## 用途

NIBN JMD 汇集日本多个地区采集的人体肠道微生物组数据，并连接人口学、饮食、营养摄入、生活方式及身体活动等表型信息。它是少数明确包含饮食/生活方式字段的微生物组资源，可用于从特定人群队列发现有较丰富宿主信息的数据。

## 覆盖对象与数据层级

- 官方页面报告整体数据库包含 4,578 条 16S rRNA 基因扩增子数据和 4,302 条 shotgun 数据；其中公开版当前显示 2,273 个样本、来自 2,068 名参与者。
- 公开版覆盖九个地区，并提供地区、年龄、性别、饮食和营养摄入等信息。年龄以年龄组形式展示以保护隐私；纵向样本可能重复对应同一参与者。
- 数据库总体还包含运动/身体活动等表型信息。部分详细表型并未公开，只向通过伦理审查的合作机构提供。
- 数据库研究论文报告每个样本含基本信息，并可能有饮食、营养摄入、生活方式及身体活动字段；具体字段依队列而异，不应假定每个样本都有全部字段。

## 如何使用

1. 查看 [NIBN JMD 数据库说明](https://microbiome.nibn.go.jp/microbiome-database/) 和 [公开版入口](https://jmd.nibn.go.jp/)。公开版页面列出可选样本 ID、年龄、性别、采样月份和可用 assay；先确认目标数据是否在公开子集内。
2. 自 2026-02-05 起，浏览完整数据需要注册账户并登录；官方说明账户有效期为一年。不要把注册访问误认为无需条件的匿名开放下载。
3. 公开版可用于样本选择和微生物组成/metadata 可视化与关联探索。若需要逐样本原始序列，沿研究论文中的 DDBJ/DRA 项目 accession 返回原始归档核查。
4. 需要公开子集以外的详细表型时，按官网说明申请合作及伦理审查；本资源索引不提供或复制受控表型数据。

## 能提供的信息与限制

- **适合：** 日本人群肠道微生物组队列；年龄、性别、地区以及部分队列中的饮食、营养和生活方式信息；16S/shotgun 的队列和样本发现。
- **登录与数据范围：** 官方公开页面要求建立账户；更详细的健康/表型信息可能需要经批准的合作访问。
- **年龄与隐私：** 公开版年龄以分组形式呈现。年龄组不是个体精确年龄。
- **ID 映射：** NIBN JMD 样本 ID、参与者 ID 与 DDBJ/DRA 的 project/sample/run accession 属于不同标识层级。论文列有项目级 DRA accession；在未核实逐样本 crosswalk 前，不应将项目 ID 当作样本映射。
- **分析结果：** NIBN JMD 同时是 MANTA 集成分析平台；可视化或相关性结果不等于提供可下载的原始测序文件。
