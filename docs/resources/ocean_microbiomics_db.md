# Ocean Microbiomics Database (OMDB)

**类型：** 全球海洋 genome-resolved 数据资源；**目录层级：** Extended；**状态：** active_verified（官方介绍页明确核心浏览/搜索/下载能力；本轮未执行查询或下载）；**核查：** 2026-11-11

OMDB 当前官方页列出 12,347 个有坐标样本、274,282 个重建基因组和 31,058 个 prokaryotic species-level units；提供 genome/sequence/BGC 搜索、交互式采样地图及 supporting data 下载。官方标注数据可按 CC BY 4.0 使用。此轮核实的是官网描述，没有实际下载或核对单个 accession。

**适用：** 从海洋位置、样本或研究线索追查采样上下文、MAG、基因和生物合成基因簇。

**名称区分与限制：** OMDB 强调 genome-resolved 样本、MAG、BGC 与地图；Ocean-M 是另一项多组学海洋数据库，含转录组、代谢组、蛋白组等模块。两者都不提供人类临床表型。
