# Earth Microbiome Project (EMP)

**类型：** 跨生态系统协作项目、标准化样本/序列整理数据与数据发现入口；**目录层级：** Core；**状态：** active_verified

EMP 的 observation tables、sample metadata、mapping files、序列/树和多样性结果通过 Zenodo、项目 FTP 与 Qiita EMP portal 发布。Qiita 中的 EMP 及其他样本可通过 Redbiom 按样本 metadata 或 observation data 搜索。EMP 还维护 EMP Sample Type Ontology（EMPO）和 metadata guide。

**适用：** 从土壤、海洋、淡水、宿主相关等生态系统寻找跨研究样本；使用 EMP 数据、metadata mapping 和 EMPO 作为生态样本分类或研究间比较的参考。

**限制：** EMP 是特定协作项目和整理版数据，不是所有微生物组样本的通用 archive。查询入口和下载文件可能覆盖不同数据子集；样本 metadata 与测序 preparation/context 需要分别理解。项目目前不再接收新样本，但已有数据仍可获取。
