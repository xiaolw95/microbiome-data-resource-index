# AgMicrobiomeBase

**类型：** UK Crop Microbiome Cryobank 数据目录与归档链接；**目录层级：** Extended；**状态：** active_partial

2023 年 UK Crop Microbiome Cryobank 论文介绍了 AgMicrobiomeBase 项目目录，用于连接 crop/soil microbiome samples、序列数据和相关 metadata，并将目录与 ENA、MGnify、BioSamples 等公共资源关联。论文描述的目标作物包括大麦、燕麦、油菜、甜菜和小麦，样本涉及 bulk soil 与 crop rhizosphere。该项目也建设低温保存的 soil microbiome、bacterial/fungal isolates 与 DNA collection。

**适用：** 按作物、土壤类型和 rhizosphere/bulk-soil 场景寻找农业微生物组；沿 BioSample/ENA/MGnify accessions 回查公开测序记录。

**限制：** 项目网页的交互 dashboard 在本轮未能渲染，字段筛选和批量导出能力尚未核实。复用前应检查门户与底层 archive 的当前使用条款；公开序列可沿论文/门户提供的 ENA、MGnify 链接回源。目录未对外部页面做批量抓取。
