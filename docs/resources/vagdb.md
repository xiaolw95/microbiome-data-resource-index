# VagDB

**类型：** 阴道微生物 16S 参考序列集；**目录层级：** Extended；**状态：** active_verified（Zenodo 文件可下载）

VagDB 提供适用于 DADA2 分类的阴道特异性 16S reference FASTA，基于发表过的 582 种人阴道细菌，使用 GTDB release 207 构建，并与 SILVA 138 taxonomy 交叉核对。

**适用：** 对 vaginal 16S 数据进行更有针对性的分类，或与通用参考库交叉核查。

**限制：** 这是参考序列资源，不包含公共研究的 BioSample、受试者、年龄、健康状态或行为 metadata。

**来源：** [Zenodo 文件与版本](https://zenodo.org/records/17452627) · [2026 论文](https://doi.org/10.3390/microorganisms14010128)
