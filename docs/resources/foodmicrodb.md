# FoodMicroDB

**类型：** 食品微生物组 amplicon 整理平台；**目录层级：** Extended；**状态：** active_verified（2026-11-10）

2024 论文报告 6,358 个 amplicon 样本、108 个项目、62 类食品和 4,710 个微生物分类单元。它整理项目—样本关系与 food / food-sourced organism 关系，支持组成分析、跨食品比较和时间序列浏览。

**适用：** 从食品类别、发酵和生产场景寻找已整理的 16S/18S/ITS 研究，再沿项目和样本关系回到原始研究。

**限制：** 食品来源不是消费者饮食或 participant diet。页面下载/API 及许可应按实际访问再核对；不能代替 raw-read archive。

**来源：** [官网](https://www.bic.ac.cn/FoodMicro/) · [GitHub](https://github.com/yli085/FoodMicroDB) · [2024 论文](https://doi.org/10.1002/imo2.40)
