# Omics Database of Fermentative Microbes (ODFM)

**类型：** 发酵食品微生物组学资源；**目录层级：** Legacy；**状态：** legacy（论文所列门户本轮不可访问）

2021 Scientific Data 论文描述一个发酵食品微生物数据系统，收录细菌、古菌、真核微生物和病毒的 genome、metagenome、metataxonome 与 transcriptome 序列；提供 BLAST/ANI 查询、序列和注释下载，并关联发酵微生物菌种资源。

**适用：** 作为 kimchi、发酵蔬菜、海鲜、酱类、醋、啤酒、奶酪、清酒和酸奶相关菌株与序列的历史发现线索。

**限制：** 论文所列 odfm.wikim.re.kr 本轮无法访问；当前服务、数据迁移和许可未确认。它偏序列/菌株，不是人体摄入或样本 metadata 数据库。

**来源：** [2021 论文](https://doi.org/10.1038/s41597-021-00895-x) · 历史门户：https://odfm.wikim.re.kr/
