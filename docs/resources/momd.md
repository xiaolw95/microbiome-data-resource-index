# MOMD（Mouse Oral Microbiome Database）

**类型：** 小鼠口腔菌群分类与基因组参考库　**目录层级：** Extended　**状态：** `active_verified`（核查：2026-11-10）

## 它是什么

MOMD 汇集小鼠口腔相关的全长 16S rRNA 参考序列、分离株和 draft genomes，提供分类浏览、16S BLASTN、基因组注释浏览及下载。官网当前说明收录 205 个 Mouse Oral Taxa（MOT）。

## 何时使用

适合解释小鼠口腔 16S 序列或基因组、核对 MOT 分类、查找口腔分离菌/参考序列，或为小鼠口腔微生物研究建立分析参考。

## 与样本 metadata 的边界

MOMD 的主体是分类学和参考序列/基因组信息，不是一个覆盖多项目受试小鼠年龄、性别、饮食、健康状况和采样时间的样本 metadata 仓库。不要将资源的宿主/部位描述误作每个样本均具备的字段。
