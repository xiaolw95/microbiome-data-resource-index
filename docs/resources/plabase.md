# PLaBAse

**类型：** 植物相关细菌数据库和分析资源；**目录层级：** Extended；**状态：** active_verified（检索页可用；批量下载状态需留意）；**核查：** 2026-11-11

官网当前检索页报告 5,565 个植物相关细菌菌株，可按 taxonomy、植物 sphere 和细菌对宿主植物的 phenotype 筛选；另有 PIFAR-Pred、PGPT-Pred 序列分析工具。此轮核实的是页面和筛选说明，没有提交查询或下载全量记录。

**适用：** 按植物生态位或菌株性状查参考基因组与植物互作背景。

**限制：** 这是菌株/基因组知识库，不是公共测序样本索引。官网显示版本较早，下载页标注开发中；批量数据和工具使用前应核对。
