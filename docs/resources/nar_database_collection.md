# NAR Molecular Biology Database Collection

**类型：** 数据库论文与资源目录；二级发现入口　**层级：** Extended　**核查：** 2026-11-11

## 它是什么

Nucleic Acids Research（NAR）的年度 Database Issue 发布数据库资源论文和既有数据库更新；配套的 Molecular Biology Database Collection 用较短摘要展示更广范围的生物学数据库。该渠道对发现新资源、获取原始数据库论文和追踪年度更新很有价值，但覆盖跨越多个生物学领域。

## 适合怎么用

- 从年度总览表和条目主题筛选 microbiome、microbial、metagenome、virome、AMR 等候选；
- 查看数据库论文对真实对象、数据来源、查询/下载方式的描述；
- 再打开官方 portal/API 验证当前功能、版本、访问条件和资源状态。

## 限制

论文发表不代表网站或 API 仍在运行；NAR 年度目录也不等同于微生物组资源完整清单。2026 年总览文章报告当年的 Collection 快照含 2,173 条，并称过去一年复核 899 条、新增 96 项、移除 319 个已停用 URL。这个数字应带年份引用，不作为实时计数或覆盖完整性的保证。
