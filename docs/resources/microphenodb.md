# MicroPhenoDB

**类型：** 微生物—疾病表型知识库；**目录层级：** Legacy；**状态：** legacy（两个历史服务地址未能打开）

2020 年论文报告 5,677 个去重 microbe–disease associations，涵盖 1,781 个微生物、542 种疾病和 22 个以上身体位点；另有核心基因、毒力因子、抗药性注释，并描述网页搜索、CSV 和 JSON API。

**适用：** 为疾病—微生物关联提供历史文献和知识线索。

**限制：** 本轮访问两个历史官网地址均失败，未确认当前官方 API 或完整下载。association 是疾病层面的文献知识，不是某个 BioSample 的临床记录，也不证明因果。

**来源：** [2020 原始论文](https://doi.org/10.1016/j.gpb.2020.11.001) · 历史服务地址：http://www.liwzlab.cn/microphenodb；http://lilab2.sysu.edu.cn/microphenodb
