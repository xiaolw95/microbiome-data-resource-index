# CNGBdb Microbiome Database (MDB)

**类型：** 微生物组数据查询平台；**目录层级：** Core；**状态：** active_partial（官方帮助可读，当前主页访问超时）

官方帮助说明可按 sample ID、project ID 或 microorganism 搜索；浏览 Project、Sample、Experiment/Run 和 Assembly；按 170 多项 phenotype 过滤样本。平台还提供人类和模式动物的 gene catalogs、FASTA、注释与丰度 profile。

**名称区分：** 这是中国国家基因库 CNGBdb 下的 MDB，与美国的 MicrobiomeDB（microbiomedb.org）不同。

**限制：** CNGB 页面在本轮超时，当前交互和记录覆盖尚未复核。帮助页列出的字段不代表每个样本均完整填写。

**来源：** [MDB 官网](https://db.cngb.org/microbiome/) · [官方帮助](https://db.cngb.org/microbiome/help/) · [re3data 记录](https://www.re3data.org/repository/r3d100012917)
