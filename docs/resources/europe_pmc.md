# Europe PMC

**类型：** 文献检索与出版数据服务　**目录层级：** Core supporting　**已核查：** 2026-11-10

## 它是什么

Europe PMC 提供生命科学论文记录、摘要、开放获取全文链接及 REST API，可用于从项目号、DOI/PMID/PMCID、作者或文本查询相关论文。

## 可提供什么

- PMID、PMCID、DOI、标题、摘要和出版信息；
- 检索论文中出现的数据 accession 或数据可用性线索；
- 对其有全文的文章提供全文搜索/访问入口；
- 论文与已有数据库记录间的文献关联。

## 何时使用

由 BioProject/Study 或 accession 搜索候选论文，优先判定原始数据论文，再将论文转入全文、补充文件和作者样本名 crosswalk 核查。

## 限制

检索命中 accession 只说明文本中提到了 ID，未必表示该论文产生了数据；可能是复用、引用或背景提及。论文级信息不自动等于样本级 metadata，全文覆盖也受开放获取范围限制。
