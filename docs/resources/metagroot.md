# metagRoot

**资源类型：** microbial knowledgebase　**优先级：** extended　**相关性：** supporting　**状态：** `active_partial`　**核查：** 2026-11-10

## 能提供什么

metagRoot 专注植物根际及根内微生物蛋白家族。2026 年 NAR 论文报告 71,091 个蛋白家族，数据来源包括 1,199 个 metagenomes、327 个 metatranscriptomes 和 2,978 个参考基因组，并提供多序列比对、HMM、分类/功能注释、生态系统上下文、CRISPR 信息和 AlphaFold2 结构预测。论文也指向 Zenodo 批量数据存档。

## 适合什么任务

- 从作物、根际、根内生境或蛋白功能问题开始发现植物相关微生物组数据。
- 检索根际子环境相关的蛋白家族和序列，下载 HMM/结构/注释数据。
- 沿数据来源追到 IMG/M 中的研究和基因组记录。

## 边界与注意事项

- 资源主对象是蛋白家族和相关序列，不是逐样本/逐植物的临床式 metadata 表。
- 生态标签适合解释蛋白家族背景，但不应替代原始项目的 sample accession 和采样设计。
- 本轮门户链接未能正常加载；论文与 Zenodo 数据存档可作为可追溯入口，portal 状态保留 partial。
