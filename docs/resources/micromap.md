# MicroMap

**类型：** 人体微生物代谢网络可视化资源　**目录层级：** Extended　**状态：** `active_verified`　**已核查：** 2026-11-10

## 它是什么

MicroMap 是与 Virtual Metabolic Human（VMH）互联的人体微生物代谢网络和模型可视化资源。2025 年论文描述了覆盖 257,429 个微生物基因组尺度代谢模型的可视化，含 5,064 种独特反应、3,499 种代谢物（包括 98 种药物），并可用于比较不同微生物的代谢能力和浏览计算模型结果。

## 适用场景与边界

它适合探索菌株代谢潜力、饮食/药物相关代谢网络及模型结果，不是样本 accession 搜索工具，也不提供常规参与者年龄、性别、疾病、饮食或采样元数据。不能将反应/代谢物模型中的营养或药物信息解读为某个来源样本的实际饮食/用药暴露。
